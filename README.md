# Fruit Catcher (iPhone-friendly)

A tiny browser game that works great on iPhone Safari.

## Play locally

1. In this folder run:
   ```bash
   python3 -m http.server 8000
   ```
2. Open `http://localhost:8000` on your computer **or** on your iPhone (same Wi-Fi) using your computer's local IP.

## Rules

- Catch fruit to score points.
- Avoid bombs.
- You lose a life for each missed fruit or bomb you catch.
- Game ends at 0 lives.
